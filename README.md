# 🌾 ติวสอบ นักวิเคราะห์นโยบายและแผน (กระทรวงเกษตรและสหกรณ์)

เว็บแอปฝึกทำข้อสอบแบบ static — ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์

## คลังข้อสอบ
52 ข้อ 6 หมวด: บริหารราชการแผ่นดิน, ข้าราชการพลเรือน, ข้อมูลข่าวสาร/PDPA,
วิธีปฏิบัติราชการทางปกครอง/ละเมิด, สารบรรณ-พัสดุ, ภารกิจ สป.กษ.

## วิธีใช้งานบนเครื่อง
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย

## Deploy ขึ้น GitHub Pages
1. สร้าง repo ใหม่ แล้ว push ไฟล์ทั้งหมดขึ้น branch `main`
2. ไปที่ **Settings → Pages**
3. Source เลือก **Deploy from a branch** → branch `main` → folder `/ (root)`
4. รอ 1-2 นาที เว็บจะขึ้นที่ `https://<username>.github.io/<repo>/`

## การเพิ่มข้อสอบ
แก้ไขเฉพาะไฟล์ `questions.js` เพิ่ม object ต่อท้าย array:

```js
{ cat: 0,                       // ดัชนีหมวดใน CATEGORIES
  q: "โจทย์คำถาม",
  c: ["ตัวเลือก ก","ข","ค","ง"],
  a: 1,                         // ดัชนีคำตอบที่ถูก เริ่มนับ 0
  e: "คำอธิบายเฉลย" }
```

## หมายเหตุ
